Ergänzung zum Web-Update 3.7.51

historical_edges.csv
Quelle: AP33 G4 Historie
Enthält die historisch geführten Kanten in separatem Layer.
Aktuelle und historische Rollen dürfen in der Defaultansicht nicht vermischt werden.

cluster_summary.csv
Quelle: AP30 Cluster Export
Enthält die Clusterzusammenfassung für Cluster 0 bis 63.
Die vollständige Organisation→Cluster-Zuordnung bleibt in cluster_export.csv.

Hinweis zur Kompatibilität:
Die Dateien sind aus den aktuellen Mastertabellen in der vorgesehenen Tabellenform erzeugt.
Falls Claude Code mit „bisherige Form“ ein exakt abweichendes altes Spaltenschema meint,
bitte lediglich die Headerzeile der bisherigen historical_edges.csv und cluster_summary.csv schicken.
Dann kann das Schema 1:1 nachgebaut werden.
